# Manifest Destiny — Releases

**Be the wizard-emperor of Valheim.** A rideable red-fire dragon (hold click: the fire *pours*),
castle-building villager hordes, community-blueprint castles, a capital that grows with your
empire, self-laying roads, and an escalating world war whose frontier marches outward until the
map is yours.

## Get it

Grab the newest `ManifestDestiny-X.Y.Z.zip` from **[Releases](../../releases/latest)**.

## Install — Windows, one line

Open PowerShell and paste:

```powershell
irm https://raw.githubusercontent.com/VELLORAAI/manifest-destiny-releases/main/install.ps1 | iex
```

Then launch Valheim from Steam like always and join your friend's world. That's the whole thing.

## Other installs (two minutes)

**Windows (easiest):** [r2modman](https://thunderstore.io/c/valheim/p/ebkr/r2modman/) →
install **BepInExPack Valheim** → Settings → *Import local mod* → pick the zip → launch modded.

**Or install nothing at all:** if your host runs the mod, just join their world with vanilla
Valheim — you'll see everything (dragon, fire, castles, warcamps). Only the host casts.

Full guide, including manual Windows and macOS installs: [FRIENDS.md](FRIENDS.md).

## Requirements
- Valheim (Steam)
- BepInEx 5.4.x (BepInExPack Valheim)

Every asset is the game's own — the mod ships no models or textures, so it survives art updates.
